==============================================================================
LINUX (BASH / ZSH) SETUP & EXECUTION STEPS
==============================================================================

Step 1: Clone or Navigate to the Repository
--------------------------------------------
cd formula1-lakehouse

Step 2: Create and Activate Virtual Environment
------------------------------------------------
python3.11 -m venv .venv
source .venv/bin/activate

Step 3: Install Required Dependencies
-------------------------------------
pip install --upgrade pip
pip install -r requirements.txt

Step 4: Configure Environment Variables
---------------------------------------
cp .env.example .env

Step 5: Generate Historical Sample Datasets (8 Formats)
-------------------------------------------------------
python generate_sample_data.py

Step 6: Run End-to-End Pipeline Execution
-----------------------------------------
python orchestration/pipeline.py --stage all

Step 7: Run Incremental Backfill Engine
---------------------------------------
python orchestration/backfill.py --start-year 2021 --end-year 2022

Step 8: Execute Automated Pytest Test Suite
-------------------------------------------
pytest tests/ -v

Step 9: Launch Interactive Analytics Dashboard (Streamlit)
----------------------------------------------------------
streamlit run dashboard/app.py
