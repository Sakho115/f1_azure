# Streamlit Dashboard UI & Layout Documentation

## Visual Layout Overview

### 1. Championship Standings View
- **Driver Leaderboard**: Interactive horizontal bar chart colored by team constructor with points metric cards for P1, P2, P3.
- **Constructor Championship**: Donut chart representing team points share across the season.

### 2. Telemetry & Pit Stop View
- **Starting Grid vs Finish Position Scatter**: Interactive scatter plot visualizing overtaking moves and positions gained.
- **Pit Stop Efficiency**: Bar chart comparing constructor average pit stop duration (seconds) and season fastest stops.
- **Qualifying Pace**: Net grid positions gained/lost bar chart.

### 3. World Circuits View
- **Global Track Map**: Interactive Plotly scatter geo map showing circuit coordinates worldwide.
- **Elevation Profiles**: Bar chart of track altitudes above sea level.
